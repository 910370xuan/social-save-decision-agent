# 社群收藏決策助理 Agent 進度報告

## 1. 專案簡介

本專案旨在協助 Threads、IG、FB 等社群平台使用者，在瀏覽大量社群內容時，快速判斷哪些連結值得收藏、哪些不值得保留，並減少「收藏後找不到」、「資訊過期」以及「只收不用」等問題。

此 Agent 的核心概念，是在使用者貼上連結後，先進行內容分類、真實性評估與可用性判斷，再提供收藏建議與原因說明。未來也計畫依據地點與時間，推薦適合的行動方案；對知識型內容則可轉成文字整理，並提供學習方案。

---

## 2. 目標使用者與痛點

### 目標使用者
- Threads、IG、FB 等社群平台使用者
- 經常透過社群平台發現活動資訊、地點資訊、學習資源與技能內容
- 需要快速判斷資訊是否值得保留與後續行動的人

### 主要痛點
- 收藏後找不到：資訊散落在不同平台或收藏夾中，難以後續查找
- 資訊會過期：活動、地點或時間敏感資訊可能在短時間內失效
- 只收不用：使用者儲存大量連結，但缺乏判斷與後續行動規劃

---

## 3. 使用場景

### 對話範例 1：地點活動類內容判斷

使用者貼上某個活動或地點資訊連結：

- Agent 先判斷該連結屬於「地點活動類」
- 檢查資訊是否真實、是否具備公開時間、地點與有效性
- 評估內容是否適合收藏，並判斷是否有即時行動價值
- 若適合收藏，Agent 可說明原因；若不適合，則指出原因，例如資訊過期、內容不明確或缺乏可信依據
- 未來規劃中：依照地點與時間建議可能的行動方案

### 對話範例 2：知識技能類內容判斷

使用者貼上某篇學習資源或技能教學連結：

- Agent 判斷該連結屬於「知識技能類」
- 評估內容的真實性與可用性，確認是否值得保留
- 若值得收藏，Agent 可建議收藏並說明其學習價值
- 若不建議收藏，則說明內容可能不夠可靠、缺乏實用性或不符合個人需求
- 未來規劃中：將內容轉成文字整理，並提供學習方案

## 5. 預計使用的 Coze 功能積木

以下為目前規劃中的 Coze 功能積木，僅作設計方向，未表示已完成：

- 連結輸入模組：接收使用者貼上的社群連結
- 分類邏輯模組：判斷內容屬於「地點活動類」或「知識技能類」
- 真實性評估模組：檢查資訊是否可信、是否具備足夠證據與合理性
- 可用性評估模組：判斷內容是否有實際收藏與使用價值
- 決策建議模組：建議收藏或不收藏，並說明原因
- 後續推薦模組：規劃中，未來可依地點與時間提供行動方案
- 知識整理模組：規劃中，可將知識類內容轉成文字，並提供學習方案
